# AppleMetaFix

AppleMetaFix 是一个基于 Electron + React + TypeScript 的本地音乐元数据管理工具，用于扫描、分析和整理个人音乐库。

## 当前版本

`v0.1.0`

当前版本重点完成音乐库扫描、元数据显示、歌词检测和本地音乐信息浏览功能。

## 已实现功能

### 音乐库扫描

- 支持扫描本地音乐文件夹
- 自动识别音频格式
- 读取音乐基础元数据
- 统计音乐库信息

支持格式：

- FLAC
- MP3
- M4A
- WAV

扫描统计包含：

- 歌曲数量
- 艺术家数量
- 专辑数量
- 音乐库容量
- 格式分布
- 封面数量
- 歌词状态

### 元数据显示

列表展示：

- 封面
- 标题
- 艺术家
- 专辑
- 流派
- 歌词状态

详情页展示：

- 专辑封面
- 标题
- 艺术家
- 专辑
- 专辑艺术家
- 作曲家
- 流派
- 年份
- 音频格式
- 比特率
- 采样率
- 位深
- 文件信息

### 歌词检测

支持检测：

- 内嵌歌词
- 外部 LRC 歌词

歌词状态显示：

- 内嵌
- LRC
- 内嵌 + LRC
- 无歌词

### 列表交互

- 点击歌曲查看详情
- 当前歌曲高亮
- 键盘 ↑ / ↓ 切换歌曲
- 自动滚动到当前选中歌曲
- 支持搜索歌曲、艺术家、专辑、流派

### 窗口体验

- Electron 桌面应用
- 自适应窗口布局
- 左右面板独立滚动
- 窗口尺寸记忆
